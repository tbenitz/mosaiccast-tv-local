How PiP Studio works

Main + overlays: the first source is the main video. New sources float above it, not beside it. Grab any small video to drag; use its bottom-right corner to resize. Double-click to promote it to main. You can also control them from the source list.

Fullscreen: fills the display with the main video and its overlays, with the controls appearing on mouse movement and disappearing when idle. Open Sources (H) to mute, reposition, show/hide, resize, or promote videos. Drag any overlay and resize from its lower-right corner.

Float PiP: Chrome's Document Picture-in-Picture opens one always-on-top window containing the main video and movable overlays. Drag or resize that outer window using Chrome; rearrange inner overlays directly. When unavailable, single composite-video PiP is attempted instead.

Android TV remote: Keyboard or remote events received by the HTML page use arrows to select streams, OK to pause local files or freeze the captured preview, +/- for volume, and A to switch Solo/Mix audio. Chrome Cast tab mirroring normally does not relay Android TV remote button presses to this page. This HTML cannot pause the original shared website; that needs a separately supported browser-extension or Cast receiver integration.

Sources and audio: open each tab or screen through Chrome's sharing prompt and check “Share tab audio” when available. Each source has separate mute and volume controls. Sources must be added again after reloading the page.

Shortcuts: F = fullscreen, H = source manager, P = floating window, M = mute all, 1–9 = make source main, Esc = close manager / exit fullscreen.
