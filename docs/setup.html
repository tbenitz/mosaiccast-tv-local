MosaicCast TV · Setup

← Open the studio

1. Open the web studio

On your Chromebook, open MosaicCast TV Studio. Select Share tab / screen and choose the videos you want. Chrome may ask you to allow tab audio. Set Grid or PiP, then click fullscreen. Chrome tab casting sends a picture to the TV but does not relay your Mi Box remote's keys back to this page.

2. Full two-way remote control

For the Mi Box D-pad and OK button to control the Chromebook sender, install the separate MosaicCast Chromebook extension and Android TV receiver APK from the complete project package. The native receiver connects to a local WebRTC sender on the same network; its pairing PIN is used only for local setup.

The receiver must be built as an APK via GitHub Actions or Android build tools. This website alone cannot install it or supply remote key presses over ordinary Cast.

3. Quality and troubleshooting

Use 1080p at 30 FPS as your initial wireless target, with both devices on the same Wi-Fi network. Start with demo feeds. If the Android receiver's remote has no effect, ensure you're in the native receiver app, not Chrome Cast.
